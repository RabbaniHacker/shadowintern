# 🤝 Contributing to ShadowIntern

Thanks for your interest! This project is in early design/research phase.

## Where Help Is Needed

| Area | What's needed |
|---|---|
| Agent Design | Help designing the Company Intelligence scraping pipeline |
| Frontend | Dashboard mockups (Figma or code) |
| Research | Related papers, evaluation methodology ideas |
| Data | List of public data sources per company |
| Testing | Students willing to do a 4-week shadow trial |

## How to Contribute

1. Open an **Issue** describing your idea or what you want to work on
2. Wait for a response before starting work
3. Fork → branch → PR

## Contact

Open an issue or reach out via GitHub Discussions.
